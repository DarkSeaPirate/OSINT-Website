# 🛡️ OSINT Website

A modern and responsive OSINT (Open Source Intelligence) website built using HTML, CSS, and JavaScript. It provides cybersecurity resources, OSINT tools, books, and educational content through a clean and user-friendly interface.

## 🚀 Features

- Responsive Design
- OSINT Resources
- Cybersecurity Books
- Detection & Security Pages
- Contact Form
- Pure HTML, CSS & JavaScript

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
